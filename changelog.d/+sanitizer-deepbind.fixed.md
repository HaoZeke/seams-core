The sanitizer suite no longer loads anything with `RTLD_DEEPBIND`, which ASan refuses. Julia opens libpcre2 that way, so `chill_plus_fronts_agree` and `docs_api_julia` are not registered under ASan, and `language_fronts`, `docs_examples` and `docs_video_tapes` skip their Julia parts. OVITO loads matplotlib's FreeType module that way, so `q4_q6_equal`, the paper pipeline, gallery and molecule renderers load it before OVITO. `b_sanitize` builds register the Python binding tests again; only the R and Julia comparison stays out.
