The library builds with Clang and OpenMP on x86-64 again. The AVX-512 VNNI and fp64 GEMM rows of the Ozaki kernels run in their own AVX-512 functions, called from the parallel loop, because Clang's OpenMP outline does not inherit the target attribute of the function around it; the CPU dispatch is unchanged. The sources, engines and tests also build under `-Werror=sign-conversion`, `-Werror=shorten-64-to-32`, `-Werror=shadow` and `-Werror=unknown-attributes`, through explicit index conversions and renamed shadowing locals, and the GCC-only `optimize` attribute is no longer seen by Clang. No result changes.
