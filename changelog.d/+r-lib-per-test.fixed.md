`docs_api_r`, `docs_examples`, `chill_plus_fronts_agree` and `docs_video_tapes` each install the `dseams` R package into their own `build/r-lib/<test>` library on every run. They used to share `build/docs-r-lib`, so under parallel `meson test` one test's `R CMD INSTALL` could remove the package while another loaded it, and `docs_video_tapes` never installed it at all and failed when it ran first.
