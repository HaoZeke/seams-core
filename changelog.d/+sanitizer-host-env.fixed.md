Under `capi_sanitize` or `b_sanitize` with ASan, a default `sanitize` test setup preloads the shared ASan runtime into every test, turns off its link-order check, leaves LeakSanitizer off for hosts such as CPython, numpy and OpenMPI that leak at exit by themselves, and turns off the OpenMPI memory patcher, which rewrote the ASan `mprotect` interceptor and crashed `plumed_driver` with SIGILL. Clang builds link the shared runtime with `-shared-libsan`. The C API tests, the Catch2 unit tests, the dump fault-injection tests (with the runtime ahead of the fault preload) and `lammps_hook` keep LeakSanitizer with the libomp suppression in `fuzz/lsan.supp`; `lammps_hook` suppresses leaks only in the UCX and libomp frames of the LAMMPS wheel.
