C API: `seams_system_set_positions` checks and writes the coordinates in one pass, into a second set of per-atom records that it swaps in only when every value is finite, so a failed reload still keeps the old frame. In a trajectory loop at 110592 atoms it now costs within a few percent of writing the coordinates into the C++ frame in place, against 18% more before; the handle holds twice the per-atom memory once it has been reloaded.
