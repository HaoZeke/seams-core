# Seams

Seams is an example of the stable C API in `include/seams.h`
(`libseams`): it works on coordinates the caller passes in and reads no
files. It is not registered. The Julia package to install is Dseams
(`bindings/julia/Dseams`), which reads trajectories and covers the
analyses of the R package.

Ice Ih through the frame front is 128 hexagonal waters and 256 primitive
six-rings. `Dseams.chill_plus` and `Dseams.primitive_rings` assert both.
`six_rings` returns that six-ring count.
