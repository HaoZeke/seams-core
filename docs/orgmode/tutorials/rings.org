#+TITLE: Primitive rings
#+OPTIONS: toc:nil num:nil

A primitive ring is a cycle that survives the Franzblau shortest-path test.
For every pair of vertices on the cycle, a shortest path between them lies on the cycle.
Distances are read on the whole graph, and only then are levels below the source cleared.
The hexagon with vertex 0 joined to vertices 1 and 4 is the worked example on the primitive-rings page.
~pydseams.band.ring_census~ counts those rings on ~Frame.bonds_by_index~.
For an oxygen-only frame that list is the cutoff neighbour list.

The runnable copy is =docs/tutorials/test_rings.py=.

#+begin_src python
import pydseams as ds
from pydseams.band import ring_census

frame = ds.read("input/traj/exampleTraj.lammpstrj", atom_type=2)
print(ring_census(frame, max_size=8))
#+end_src

On the 250 oxygens the census is 1 three-ring, 230 four-rings, 4 five-rings, and 192 six-rings.
That census is the cutoff neighbour list, the same list ~seams chill-plus~ uses by default.
~seams rings~ prints the CLI histogram of that list. ~--max-ring~ defaults to 6, so the CLI row stops at six-rings.
