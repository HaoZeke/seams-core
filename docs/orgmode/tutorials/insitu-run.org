#+TITLE: Run in situ
#+OPTIONS: toc:nil num:nil

The cubic cell is ~engines/lammps/ice.data~, 64 atoms. LAMMPS
reads it from ~engines/lammps/in.dseams~ and calls ~seams_chill_plus~
from ~fix external~ on every second step. OpenMM builds an
eight-molecule cell in angstroms and steps it twice through
~DseamsReporter~. ~meson test docs_tutorial_insitu~ runs whichever of
those libraries is installed. When neither library is on the machine
the test exits 77 and meson records a skip.

Both paths label every atom cubic. The LAMMPS line is ~ice~ equal to
~calls~ times 64. The OpenMM line is ~openmm calls 2 ice 16~, two
frames of eight cubic molecules.

#+begin_src bash
# from engines/lammps, after meson compile -C build engines/run_hook
../../build/engines/run_hook in.dseams
PYTHONPATH=adapters/python python3 engines/openmm/test_reporter.py
#+end_src
