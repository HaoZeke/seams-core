#+TITLE: Python Frame
#+OPTIONS: toc:nil num:nil

~pydseams.read~ returns a ~Frame~. Each call below is the example the
suite runs, and the line under it is the output. The frame is
~input/traj/ice1h.lammpstrj~, 128 oxygens.

* read

#+begin_src python
>>> import pydseams
>>> frame = pydseams.read("input/traj/ice1h.lammpstrj", atom_type=1)
>>> frame.n_atoms
128
#+end_src

* steinhardt

#+begin_src python
>>> import pydseams
>>> frame = pydseams.read("input/traj/ice1h.lammpstrj", atom_type=1)
>>> q = frame.steinhardt(6)
>>> len(q["ql"])
128
>>> round(sum(q["ql"]) / len(q["ql"]), 6)
0.625855
#+end_src
