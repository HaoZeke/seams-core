* C

~include/seams.h~ and ~libseams~ are new. The ABI is 1.
Handles are opaque. Coordinates are angstroms, and a cell is the nine
LAMMPS numbers. The calls are the version and status strings,
~seams_set_num_threads~, one frame (~seams_system_create~,
~seams_system_set_frame~, ~seams_system_set_ortho~), a cutoff or mutual
neighbour list, ~seams_chill_plus~, ~seams_q4q6~, and primitive rings.
The enumerator types are ~seams_status~, ~seams_label~,
~seams_ring_symmetry~, ~seams_chill_rule~, and ~seams_graph~.

~bindings/cxx/seams_lang.h~ is the C ABI the other languages call.
A frame is read from a path or built from arrays. The new entries on
that header include ~seams_frame_set_positions~,
~seams_frame_neighbour_pairs~, ~seams_frame_steinhardt_graph~,
~seams_frame_wl~, ~seams_frame_q4_q6~, ~seams_frame_q4_q6_chill~,
~seams_frame_symmetry~, ~seams_frame_select~,
~seams_frame_from_species~, and ~seams_frames_jump_tau90~.

PydSEAMSlib and the yodaStruct Lua package stay separate repositories.
The in-tree Python module is ~dseams~.

* Engines

Each plugin is built when its library is found. ~with_lammps~ and
~with_gromacs~ default to auto. A found library whose plugin cannot be
built is an error.

| engine | call | units |
|--------+------+-------|
| LAMMPS | ~fix external~ ~run_hook~, and the copy-in compute under ~extras/lammps~ | angstroms, the LAMMPS frame |
| GROMACS | ~gmx-seams~ (~engines/gromacs/seams_ice.cpp~) reads an mdrun trajectory | nanometres scaled to angstroms; the lower-triangle tilts are read |
| OpenMM | ~DseamsReporter~ and ~InSitu.observe~ | nanometres scaled by 10 |
| PLUMED | collective variable ~SEAMS~ (~engines/plumed/SeamsColvar.cpp~) | positions scaled from nanometres; the q6 derivative passed back is ten times the angstrom derivative |

The guest PLUMED symfunc rows in ~benchmarks/rc3-sitting.csv~ were
measured on one thread because ~PLUMED_NUM_THREADS~ was unset. That is
a fact about those rows. The collective variable above is the d-SEAMS
plugin.

* Threads

~seams_set_num_threads~ sets the OpenMP width for the next call. Zero
restores the width captured at first use. ~seams::teamFor~ returns one
thread below 2048 atoms, four threads below 8192 atoms when the caller
asked for more than four, and the OpenMP width otherwise.
~seams::prepareCompute~ widens the affinity mask, calls
~omp_set_dynamic(0)~, and does not set ~OMP_WAIT_POLICY~.
~seams::adoptThreads~ leaves the OpenMP team running and sets the
linkcell width with ~lc_set_threads~. The linkcell pool is one per
process and its workers sleep between searches. Below 4096 molecules
that pool is capped at four. The orthorhombic cutoff list is shared:
each pair is counted once, even z layers together, a wrapping last
layer alone, then the odd layers. Published CHILL+ and cutoff q6 read
that list. A carried ring update enumerates changed sources with
~sourceTeam~ and sorts and merges the kept rings with ~teamFor~.

The signature-search and pool-audit sittings are the CSVs on
[[file:../explanation/trace-threads.org][the thread-control page]].

* Deprecations

The log from ~2dbefa97~ does not add a deprecation. ~--types~ is still
the alias of ~--pair-types~, and it still prints
~--types is deprecated; use --pair-types~ on stderr.

* Breaking

CHILL and CHILL+ map the default graph name ~seeded~ onto the cutoff
list. ~mutual~ is the four-nearest graph. ~seams cages~ keeps ~seeded~
as its own graph. A reader error returns exit code 2. ~seams steinhardt~
prints q4 and q6 as well as any other degree named by ~--l~.
~BondClassifier~ keeps the 2.13 layout.
