#+TITLE: Quickstart
#+OPTIONS: toc:nil num:nil

Install the engine, then classify one cubic cell. The five Python lines
and the C program below are ~meson test docs_quickstart_py~ and
~docs_quickstart_c~. Both expect 8 cubic molecules.

* Install

pip installs the Frame package. The five lines use the in-tree module,
which Meson builds.

#+begin_src bash
pip install pydseamslib
#+end_src

conda-forge has no ~d-seams~ package. It does have the toolchain, and
Meson builds the engine from this tree:

#+begin_src bash
conda install -c conda-forge meson ninja pkg-config eigen python numpy
meson setup build -Dwith_python=true
meson compile -C build
#+end_src

The same two Meson lines are the install when the compilers are already
on ~PATH~. ~-Dwith_python=true~ is the default. ~import dseams~ then
loads ~build/python~ or the installed extension. Put that directory on
~PYTHONPATH~, and ~build/src~ on ~LD_LIBRARY_PATH~.

* Five lines of Python

#+begin_export rst
.. literalinclude:: ../examples/quickstart.py
   :language: python
#+end_export

~chill_plus~ returns labels and the nine counts. Index 0 is cubic.

* Five calls in C

#+begin_src c
seams_system *sys = seams_system_create();
seams_system_set_ortho(sys, xyz, 8, 0, 0, 0, a, a, a, NULL, NULL);
seams_chill_plus(sys, 3.5, 0, SEAMS_GRAPH_CUTOFF, SEAMS_CHILL_PUBLISHED, labels, counts);
printf("cubic %d\n", counts[0]);
seams_system_destroy(sys);
#+end_src

~docs/examples/quickstart.c~ is that call on the eight-atom diamond.
The program prints ~cubic 8~.

Build the engine, read a frame, and print what this binary linked.

The in-tree mixed TIP4P dump is ~input/traj/exampleTraj.lammpstrj~ (750 atoms, 250 waters; type 2 is oxygen).

* Install the engine

Nix flake:

#+begin_src bash
nix build
./result/bin/seams --help
nix develop   # compiler, Eigen, BLAS, Catch2
#+end_src

pixi:

#+begin_src bash
pixi run setup
pixi run build
./bbdir/seams --help
#+end_src

Either path produces ~libyodaLib~, ~libseams~, and the ~seams~ CLI.
~-Dwith_python=true~ (the Meson default) also builds ~import dseams~.
~-Dwith_lua=auto~ builds ~require("dseams")~ when Lua 5.4 or LuaJIT is present.

* Read a frame

#+begin_src bash
seams read input/traj/exampleTraj.lammpstrj
#+end_src

The line is ~nop 250 frame 1 box ...~ after the oxygen guess (type 2, then type 1).
Pass ~--type 2~ to skip the guess.

* Features of this build

#+begin_src bash
seams --features
#+end_src

Each line is a compile-time backend: OpenMP, MPI, Highway SIMD, vesin, chemfiles, readcon-core, IRA/SOFI, sphericart, nauty. The Nix flake turns Eigen, BLAS/LAPACK, Catch2 and Highway on when nixpkgs provides them.
Optional wrap-git backends stay off unless a package is already in the closure.
~pixi~ enables what conda-forge put in the environment (Highway and chemfiles are in the default pixi lock).

* Runtime knobs

Knobs that change between machines and jobs are twelve-factor.
They are not compiled in and they are not ~conf.yaml~.
Defaults live in the binary.
An optional dotenv file (~SEAMS_CONFIG~ or ~./seams.env~) fills unset variables.
The process environment wins over the file.
CLI flags win over the environment.

#+begin_src bash
cp seams.env.example seams.env
seams --print-config
seams --frame 1 --last 100 --jobs 8 --type 2 --graph seeded \
  cages input/traj/exampleTraj.lammpstrj
#+end_src

The same values can be ~SEAMS_FRAME~, ~SEAMS_LAST~, ~SEAMS_JOBS~, ~SEAMS_TYPE~, ~SEAMS_CUTOFF~, ~SEAMS_CAGE_EDGE~, ~SEAMS_K~, ~SEAMS_GRAPH~, plus ~SEAMS_RESIDENT~, ~SEAMS_CELL~, ~SEAMS_OFFLOAD~, ~LINKCELL_TPP~, ~LINKCELL_BLOCK~.
~SEAMS_CAGE_EDGE~ defaults to ~2.65,3.15~ (coordinate units of the file). ~none~ leaves a signature cage bound to the face census.
~OMP_NUM_THREADS~ and ~CUDA_VISIBLE_DEVICES~ keep their usual meaning.
Analysis choice (which ~seams~ command, which ~pydseams~ call, which ~require("dseams")~ script) is not this table.

* CHILL+ and cages

#+begin_src bash
seams chill-plus input/traj/exampleTraj.lammpstrj --cutoff 3.5 --type 2
seams cages input/traj/exampleTraj.lammpstrj --type 2
#+end_src

On this fixture ~seams chill-plus~ uses the cutoff neighbour list (the default on every front) and prints 9 interfacial clathrate and 241 water.
~--graph mutual~ uses the mutual four-neighbour list and prints 1 clathrate, 7 interfacial clathrate, and 242 water.
The default cage graph is ~--graph seeded~ (mutual four-nearest seeds, union completions).
This mixed frame has no complete HC or DDC.
Cage membership is not the CHILL+ star.

* Python and Lua

~import dseams~ is the in-tree module over ~libseams~.
The Frame package is [[https://github.com/d-SEAMS/PydSEAMSlib][pydseams]]
(~pip install pydseamslib~, compiled module ~yoda~).
~require("dseams")~ is the in-tree Lua and Fennel module over the same
header. The 1.x Lua library remains
[[https://github.com/d-SEAMS/yodaStruct][yodaStruct]].
~import pydseamslib~ is an alias of ~pydseams~.

The Frame tutorial is [[https://d-seams.github.io/PydSEAMSlib/][pydseams docs]].
The in-tree Lua pages are ~docs/api/lua.md~ and ~docs/tutorials/lua.md~.
Language pages for the in-tree fronts are under ~docs/api~ and ~docs/tutorials~.

The full install matrix is [[file:howto/install.org][Install]].
The mixed-frame walkthrough is [[file:tutorials/bulk-ice.org][Classify ice on the mixed TIP4P example]].
