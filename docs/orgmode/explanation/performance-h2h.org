#+TITLE: Performance
#+OPTIONS: toc:nil num:nil

Head-to-head times for the neighbour list, primitive rings, local
\(q_6\), CHILL+, cages, and PTM. The other codes are OVITO, freud,
mdapy, ClavisCage, cycless, and SQQ. PTM is the OVITO polyhedral
template match. Linkcell scaling is the cutoff-ring list against the
older cell list.

The 884736-molecule sitting is ice and a TIP4P/ice liquid, at 1, 2, 4
and 8 threads. The rivals on that file are rings-statistics-matter,
freud, mdapy, pyscal3, PLUMED, vesin and OVITO. The file is the sitting
written at ~2ed49e87~. On the liquid, freud \(q_6\) is a hard-cutoff
rounding gap, PLUMED is a rational-switch gap, and CHILL+ matches a
counted subset of the molecules. The generated note prints those three
CSV tokens.

The figure is drawn when the book is built. It is an SVG of median
time against thread count, ice and liquid side by side.

~docs/render_h2h.py~ writes the tables from the CSVs when the book is
built. ~--check~ fails when a cell is missing from its CSV. The script
also reads ~benchmarks/one-sitting-v3.csv~ when that file is in the
tree, and adds a section for it. Until the file lands, the tables are
the sittings already recorded.
