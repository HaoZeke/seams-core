#+TITLE: C API gaps for the Lua binding
#+OPTIONS: toc:nil num:nil

~require("dseams")~ calls =include/seams.h= and nothing under
=src/include/internal=. A 1.x name whose work is a function in that
header is a direct call. A name whose work is absent raises a Lua
error. The error text is the signature below, then
~not in the public C API~. ~seams_last_error~ is the text when a
function that does exist returns a status other than ~SEAMS_OK~.

Orthorhombic LAMMPS dumps and ~# dseams-frame~ files are parsed in
Lua and passed to ~seams_system_set_frame~. That parser is the stand-in
for ~seams_system_read~. A triclinic bound line, an XYZ file, a ~.con~
file, and a chemfiles trajectory still raise the read signature.

The ring handle stores sizes and symmetry. It does not copy the
vertex list, so ~ringNetwork~ on a bare neighbour table raises
~seams_rings_vertices~.
