#+TITLE: Local q4 and q6
#+OPTIONS: toc:nil num:nil

Compute the local Steinhardt parameters on the cutoff shell. Degrees
4 and 6 use the solid-harmonic kernel. The Lechner-Dellago average is
printed beside each local mean.

* The CLI

~seams steinhardt~ prints one ~qL~ / ~qLbar~ pair per degree named by
~--l~. The default is ~4,6~. ~--l 3,4,6,12~ is the former four-degree
line. The neighbour list is the cutoff shell.

#+begin_src bash
seams steinhardt input/traj/exampleTraj.lammpstrj --type 2 --cutoff 3.5
#+end_src

#+begin_src python
# excerpt: tests/cli_surface.py
        ["steinhardt", tip, "--type", "2", "--cutoff", "3.5"],
#+end_src

* The C API

~seams_q4q6~ writes one q4 and one q6 per atom. Either pointer may be
null. On the 64-atom cubic cell the mean q6 is above 0.3.
~meson test seams_c_api~ is that check.

#+begin_src c
// excerpt: tests/test_seams_api.c
  expect(seams_q4q6(sys, 3.5, 0, q4, q6) == SEAMS_OK, "q4 q6");
#+end_src

~seams_frame_q4_q6~ is the same pair on ~libseams_lang~, with optional
averages. ~seams_q4_q6~ in ~src/include/internal/seams_c_api.h~ is the
flat entry used inside the library. It is not declared in ~seams.h~.
The installed name is ~seams_q4q6~.

Python is ~dseams.q4q6~. R and Julia ~Dseams~ export ~q4_q6~. The
~Seams~ Julia package and the Rust wrapper export ~q4q6~.

* Empty shells

An atom with no neighbour inside the cutoff has no bond in the sum.
The kernel leaves that spherical-harmonic row at zero and does not
divide by the neighbour count, so the local \(q_l\) and the
Lechner-Dellago average are both 0. freud and pyscal3 divide by that
count and store NaN.

0 is the value of the empty accumulator. Writing NaN from a switch
would put a non-number into every mean, into CHILL+, and into the
nucleation \(\bar q_6\). The neighbour list already names the empty
shell: a count of zero is that atom. There is no NaN option.

~meson test q4_q6_equal~ checks the split on a liquid frame. The atom
with an empty shell is 0 here and NaN in freud and pyscal3. Every atom
that has a shell matches pyscal3 to \(10^{-10}\).
