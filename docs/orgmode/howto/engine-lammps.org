#+TITLE: LAMMPS
#+OPTIONS: toc:nil num:nil

Build the in-run hook when liblammps is installed:

#+begin_src bash
meson setup build -Dwith_lammps=enabled
meson compile -C build
#+end_src

~run_hook~ registers a ~fix external~ callback. LAMMPS passes positions
in angstroms. Each sampled step calls ~seams_chill_plus~. The program
prints ~lammps calls N stride S ice M~. On the cubic deck shipped with
the hook, ~ice~ equals ~calls~ times the atom count.

The ice Ih dump in this repository is ~input/traj/ice1h.lammpstrj~.
~seams chill-plus~ on that file returns ~hexagonal 128~. ~seams rings~
returns 256 six-rings. ~seams steinhardt --l 6~ returns mean q6 0.625855.

#+begin_src bash
seams chill-plus input/traj/ice1h.lammpstrj --cutoff 3.5
seams rings input/traj/ice1h.lammpstrj --cutoff 3.5
seams steinhardt input/traj/ice1h.lammpstrj --cutoff 3.5 --l 6
#+end_src

~engines/lammps/compute_dseams.cpp~ is the copy-in compute. This build
does not compile it. ~meson test docs_engine_lammps~ runs ~run_hook~
when that binary is in the build and exits 77 when it is not.
