#+TITLE: Reproduce a head-to-head
#+OPTIONS: toc:nil num:nil

Each head-to-head is a Snakemake rule and, where a one-call arm
exists, an Airspeed Velocity benchmark. Both read the same script.
The pixi environment that holds the guest codes is =repro=. It is
Linux only. The pins are in =pixi.toml=:

#+begin_src toml
[feature.repro.dependencies]
freud = ">=3.0"
pyscal3 = ">=3.0"
jupytext = ">=1.16"
ipykernel = ">=6.0"
papermill = ">=2.4"
matplotlib-base = ">=3.8"
lua = ">=5.4,<5.5"

[feature.repro.pypi-dependencies]
snakemake = ">=8.0"
#+end_src

Install that environment, then run a rule by name.

#+begin_src bash
pixi install -e repro
pixi run -e repro -- snakemake literature_h2h
#+end_src

=asv.conf.json= sets =environment_type= to =existing= and
=benchmark_dir= to =benchmarks=. Point =asv run= at the repro
interpreter. The class names below are the =asv= =--bench= selectors.

#+begin_src bash
pixi run -e repro -- asv run \
  -E existing:.pixi/envs/repro/bin/python \
  --set-commit-hash "$(git rev-parse HEAD)" \
  -b h2h_literature.LiteratureMdapy
#+end_src

The 884736-molecule sitting, ice and the TIP4P/ice liquid, is
=benchmarks/paper-cells/sitting-large.csv=. Commit =2ed49e87= on
=bench/sitting-large= writes it with the rule =paper_sitting_large=:

#+begin_src bash
python3 scripts/paper_sitting_large.py --out benchmarks/paper-cells
#+end_src

That script is the one in =2ed49e87=. This checkout stores the CSV
that command produced and draws the thread figure from it when the
book is built. =scripts/plot_sitting_large_time.py= is the same
curves as a PDF, written only where =--out= says.
