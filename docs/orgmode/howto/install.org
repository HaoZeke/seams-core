#+TITLE: Install the engine
#+OPTIONS: toc:nil num:nil

Get a ~seams~ binary, ~libyodaLib~, and ~libseams~. The nanobind
module is built in this repository. Lua stays in yodaStruct.

* pixi

#+begin_src bash
pixi run setup
pixi run build
./bbdir/seams --help
./bbdir/seams --features
#+end_src

The default pixi lock includes Highway and chemfiles. Optional pixi
environments: ~ira~, ~sphericart~, ~nauty~, ~mpi~, ~docs~,
~formalanalysis~, ~repro~.

conda-forge chemfiles 0.10.4 writes an mmCIF atom with no residue as
~label_seq_id~ ~.~ and does not write ~label_entity_id~. The reader
treats ~.~ as an entity id and dereferences that missing column. A
read of the written file fails, and a write followed by a read in the
same process segfaults inside ~mmCIFFormat::read~. Meson compiles
~cmake/chemfiles_mmcif_probe.cpp~ and reads
~cmake/mmcif_no_entity.mmcif~, the one-oxygen file that release
writes. A library that does not return the oxygen at (1, 2, 3) in a
10 by 11 by 12 cell is left unused. The build then fetches tag 0.10.4
and applies ~cmake/patches/chemfiles-0.10.4-mmcif.patch~. A library
that reads the file is kept. ~cmake/ChemfilesDep.cmake~ runs the same
probe before it accepts an installed copy.
~SEAMS_CHEMFILES_FORCE_VENDORED~ skips the installed copy. The Meson
fallback sets it after the probe has already failed. The conda
compiler puts its own lib directory first on the RPATH, and that
directory already has ~libchemfiles.so.0.10~. When ~patchelf~ is on
~PATH~, the patched library is given the soname
~libseams-chemfiles.so.0.10~ so the loader does not open the
unpatched file.

* Nix flake

#+begin_src bash
nix build
./result/bin/seams --help
nix develop
nix run . -- read input/traj/exampleTraj.lammpstrj
#+end_src

The flake links Eigen, BLAS/LAPACK, Catch2, and Highway from nixpkgs.
Wrap-git backends (vesin, readcon-core, linkcell) and chemfiles stay
off unless the package is already in the closure. IRA, sphericart,
nauty, and MPI stay off. vesin is cutoff; linkcell is k-NN. Binary
cache: ~cachix use dseams~.

The flake on/off table lives on [[file:../reference/nix.org][Nix]].

* OpenMP target offload

The host-only pixi and flake builds leave ~with_openmp_offload~
off. The NVIDIA GPU path, including the Elja A100 module set and
the Meson line, is [[file:openmp-offload.org][OpenMP target offload]].

* Verify

#+begin_src bash
seams --help
seams --version
seams --features
#+end_src

The in-tree fronts are ~bindings/python~ (nanobind ~dseams._core~,
~-Dwith_python=true~, the default), ~bindings/r/dseams~,
~bindings/julia/Dseams~, ~bindings/fortran~, and ~bindings/rust~.
Engine hooks follow ~-Dwith_lammps=auto~, ~-Dwith_gromacs=auto~,
~-Dwith_openmm=auto~, and ~-Dwith_plumed=auto~.
~-Dwith_lua=enabled~ is a Meson error: Lua stays in
[[https://github.com/d-SEAMS/yodaStruct][yodaStruct]].

* Front ends and simulation interfaces

The Python and Lua front ends, the LAMMPS compute and the PLUMED
module install as in [[file:../paper/reproduce.org][Reproduce]], which
also pins the release of the d-SEAMS 2.0 paper.
