#+TITLE: In-situ CHILL+
#+OPTIONS: toc:nil num:nil

~InSitu~ in ~adapters/python/dseams_insitu/engine.py~ is the in-run
classifier. ~analyse~ and ~observe~ take positions and a box.
~analyse_file~ reads a LAMMPS dump. Both paths call
~seams_frame_chill_plus~ and ~seams_frame_rings~ in ~libseams_lang~.
That library is part of the default build. No extra ~-D~ option is
required.

#+begin_src bash
meson setup build
meson compile -C build
#+end_src

The ice Ih dump is ~input/traj/ice1h.lammpstrj~, 128 molecules of type
1, box 15.6457 by 14.7071 by 18.073 Å. CHILL+ returns 128 hexagonal
labels. The ring histogram has 256 primitive six-rings and no smaller
rings. Mean local q6 is 0.625855.

#+begin_src bash
seams read input/traj/ice1h.lammpstrj
seams chill-plus input/traj/ice1h.lammpstrj --cutoff 3.5
seams rings input/traj/ice1h.lammpstrj --cutoff 3.5
seams steinhardt input/traj/ice1h.lammpstrj --cutoff 3.5 --l 6
#+end_src

A length-3 box is stored as ~0, 0, 0, lx, ly, lz, 0, 0, 0~. The nine
LAMMPS numbers are passed through. ~meson test docs_engine_insitu~
reads this dump through ~libseams_lang~ and checks the hexagonal count
and the six-ring bin. It exits 77 when that library was not built.
