The build below used conda-forge GROMACS 2026.3, with the compiler and
Eigen already on the path. The same prefix also holds LAMMPS 2022.06.23,
OpenMM 8.6.0, and PLUMED 2.10.1.

#+begin_src bash
pixi init -c conda-forge dseams-engines
pixi add --manifest-path dseams-engines/pixi.toml gromacs lammps openmm "plumed=2.10.*"
eval "$(pixi shell-hook --manifest-path dseams-engines/pixi.toml)"
export PKG_CONFIG_PATH="$CONDA_PREFIX/lib/pkgconfig:$CONDA_PREFIX/lib.AVX2_256/pkgconfig${PKG_CONFIG_PATH:+:$PKG_CONFIG_PATH}"
export LIBRARY_PATH="$CONDA_PREFIX/lib:$CONDA_PREFIX/lib.AVX2_256${LIBRARY_PATH:+:$LIBRARY_PATH}"
export CPATH="$CONDA_PREFIX/include${CPATH:+:$CPATH}"
meson setup build -Dwith_gromacs=enabled -Dwith_lammps=enabled -Dwith_openmm=enabled -Dwith_plumed=enabled
meson compile -C build
meson test -C build docs_engine_gromacs --print-errorlogs
#+end_src

~gmx-seams~ reads a trajectory in nanometres, multiplies coordinates and
the box by 10, and classifies the frame. On
~input/traj/ice1h.lammpstrj~ the test writes a one-frame ~.gro~ and runs:

#+begin_src bash
gmx-seams -f ice1h.gro -cutoff 3.5
#+end_src

The last frame prints:

#+begin_src text
gromacs hexagonal 128 six-rings 256 q6 0.625855
#+end_src

That cell has 128 molecules. The cubic count on the same line is 0.
The call exits 0 when the census succeeds. ~meson test docs_engine_gromacs~
exits 77 when ~gmx-seams~ was not built.
