#+TITLE: Build the language fronts
#+OPTIONS: toc:nil num:nil

The nanobind module =dseams._core= is built in this repository when
nanobind is found. R and Julia call =libseams_lang=, which is built
with the engine and does not reimplement the classifiers. The released
Frame package remains [[https://github.com/d-SEAMS/PydSEAMSlib][PydSEAMSlib]].
The Lua module in this tree is [[file:lua.org][require("dseams")]].

* Python

#+begin_src bash
meson setup build -Dwith_python=true
meson compile -C build
#+end_src

~dseams._core~ links the in-tree ~libseams~. A missing nanobind uses
~subprojects/nanobind.wrap~. The default ~pixi run setup~ leaves
~with_python~ at its Meson default, which is true.

* R

#+begin_src bash
export SEAMS_INCLUDE="$PWD/bindings/cxx"
export SEAMS_LIBDIR="$PWD/bbdir/bindings"
export LD_LIBRARY_PATH="$SEAMS_LIBDIR:$PWD/bbdir/src${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
R CMD INSTALL bindings/r/dseams
#+end_src

The package needs ~cpp11~.
~configure~ refuses to run without the two paths.
The engine is not a CRAN system library, so this is a source package you build against a seams-core checkout.

* Julia

CxxWrap is not linked.
~libcxxwrap_julia~ is not in the pixi or Nix closure, and building it pulls a Julia sysimage into the link.
The front that ships is ~ccall~:

#+begin_src bash
export SEAMS_LANG_LIB="$PWD/bbdir/bindings/libseams_lang.so"
export DSEAMS_ROOT="$PWD"
julia --project=bindings/julia/Dseams -e 'using Pkg; Pkg.instantiate()'
julia --project=bindings/julia/Dseams bindings/julia/Dseams/test/runtests.jl
#+end_src

* Lua and Fennel

~-Dwith_lua=auto~ builds ~dseams_core.so~ for Lua 5.4 and for LuaJIT.
~require("dseams")~ and ~(require :dseams)~ call ~seams.h~.
The how-to is [[file:lua.org][Lua and Fennel]].
~meson test lua_examples~ runs the example scripts.

* q4 and q6

The cutoff-shell solid-harmonic kernel is ~seams_q4q6~ in ~seams.h~ and ~seams_frame_q4_q6~ in =libseams_lang=. The flat name ~seams_q4_q6~ lives in ~src/include/internal/seams_c_api.h~ and is not installed.
Python is ~q4_q6~ in =bindings/python/chill_plus.py= (~SEAMS_LANG_LIB= selects the library).
R and Julia export ~q4_q6~.
The CLI command is ~seams steinhardt~. ~--l~ names the degrees (default ~4,6~). ~--l 3,12~ asks for the hydrate pair.
