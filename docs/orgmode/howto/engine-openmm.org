The build below used conda-forge OpenMM 8.6.0. ~openmm.Platform.getOpenMMVersion~
reports 8.6. The compiler and Eigen stay on the path. The same prefix
holds GROMACS 2026.3, LAMMPS 2022.06.23, and PLUMED 2.10.1. Configure
meson from that shell so ~python3~ imports ~openmm~.

#+begin_src bash
pixi init -c conda-forge dseams-engines
pixi add --manifest-path dseams-engines/pixi.toml gromacs lammps openmm "plumed=2.10.*"
eval "$(pixi shell-hook --manifest-path dseams-engines/pixi.toml)"
export PKG_CONFIG_PATH="$CONDA_PREFIX/lib/pkgconfig:$CONDA_PREFIX/lib.AVX2_256/pkgconfig${PKG_CONFIG_PATH:+:$PKG_CONFIG_PATH}"
export LIBRARY_PATH="$CONDA_PREFIX/lib:$CONDA_PREFIX/lib.AVX2_256${LIBRARY_PATH:+:$LIBRARY_PATH}"
export CPATH="$CONDA_PREFIX/include${CPATH:+:$CPATH}"
meson setup build -Dwith_gromacs=enabled -Dwith_lammps=enabled -Dwith_openmm=enabled -Dwith_plumed=enabled
meson compile -C build
meson test -C build docs_engine_openmm --print-errorlogs
#+end_src

~DseamsReporter~ reads the OpenMM context in angstroms and calls
~InSitu.observe~. The docs test loads ~input/traj/ice1h.lammpstrj~ onto
a Reference-platform context with a zero force, steps once, and prints:

#+begin_src text
openmm hexagonal 128 six-rings 256 q6 0.625855
#+end_src

The q6 mean is ~seams_frame_steinhardt_graph~ on the positions the
reporter just classified, cutoff graph, degree 6. ~meson test
docs_engine_openmm~ exits 77 when the OpenMM package does not import.
