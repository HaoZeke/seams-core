#+TITLE: OpenMM
#+OPTIONS: toc:nil num:nil

Build the C++ context hook when libOpenMM is installed:

#+begin_src bash
meson setup build -Dwith_openmm=enabled
meson compile -C build
#+end_src

OpenMM stores positions in nanometres. The plugin multiplies
coordinates and the box by 10 before ~seams_chill_plus~. The Python
reporter is ~DseamsReporter~. ~describeNextReport~ asks for positions
every ~interval~ steps. ~report~ calls ~InSitu.observe~.

On an 8-atom cubic cell every label is cubic, so the ice count equals
the atom count times the number of reports.

The ice Ih dump in this repository is ~input/traj/ice1h.lammpstrj~.
Pass those coordinates in angstroms, or in nanometres after dividing
by 10 and letting the plugin scale them back. CHILL+ returns
~hexagonal 128~. Rings are 256 six-rings. Mean local q6 is 0.625855.

#+begin_src bash
seams chill-plus input/traj/ice1h.lammpstrj --cutoff 3.5
seams rings input/traj/ice1h.lammpstrj --cutoff 3.5
seams steinhardt input/traj/ice1h.lammpstrj --cutoff 3.5 --l 6
#+end_src

~meson test docs_engine_openmm~ runs the reporter when the OpenMM
package imports and exits 77 when it does not.
