d-SEAMS reads a molecular-dynamics trajectory and names the ice in it.
The command is ``seams``. The library behind that command is ``libseams``.
``nop`` is the number of molecules in the frame.
CHILL+ labels each molecule from its four neighbours.
A hexagonal cage (HC) is ice Ih. A double-diamond cage (DDC) is ice Ic.

* Five minutes

From a checkout, with [[https://pixi.prefix.dev/][pixi]]:

#+begin_src bash
pixi run setup && pixi run build
./bbdir/seams chill-plus input/traj/mW_cubic.lammpstrj --type 1
#+end_src

That prints ~nop 4096 cubic 4096~. Every molecule in the shipped cubic cell is cubic ice.
When the compilers and Eigen are already on ~PATH~, the same build is ~meson setup build && meson compile -C build~ and the binary is ~./build/seams~.
Nix, conda, pip, Spack, and an EESSI toolchain are on [[file:howto/install.org][Install]].

* Overview

d-SEAMS 2.14 reads a molecular-dynamics trajectory and names the ice in it.
~libseams~ is the library: CHILL+, cages, primitive rings, and \(q_6\) share one cutoff neighbour list.
The ~seams~ command and the C, C++, Python, Fortran, Julia, Rust, and R fronts call that library.

Ten lines classify the cubic cell shipped in ~input/traj~.

#+begin_src bash
dump=input/traj/mW_cubic.lammpstrj
seams read "$dump" --type 1
seams chill-plus "$dump" --type 1 --cutoff 3.5
seams ovito-chill+ "$dump" --type 1 --cutoff 3.5
seams rings "$dump" --type 1 --cutoff 3.5
seams steinhardt "$dump" --type 1 --l 6
seams cages "$dump" --type 1
seams cages input/traj/genice_sI.lammpstrj --type 1 --signature 512 --cage-edge none
seams rdf "$dump" --pair-types 1,1 --cutoff 6 --bins 4
seams prisms "$dump" --type 1
#+end_src

The [[file:howto/migrate-1x.org][1.x migration]], the
[[file:explanation/performance-h2h.org][performance tables]], and the
[[file:reference/release-2.14.org][2.14.0 notes]] are the rest of this
release.

d-SEAMS (Deferred Structural Elucidation Analysis for Molecular
Simulations) classifies ice in molecular-dynamics trajectories. This
repository is the C++ engine (~libyodaLib~) and the ~seams~ CLI.

The eight-atom diamond is the other check. The Python program and the C program on
[[file:quickstart.org][the quick start]] both report 8 cubic molecules.
~pip install pydseamslib~ installs the separate Frame package (~import pydseams~).
It does not build ~seams~ or ~import dseams~.
conda-forge has no ~d-seams~ package. It does have the Meson toolchain.
Every install path is on [[file:howto/install.org][Install]].

#+begin_src bash
seams read water.lammpstrj
seams chill-plus water.lammpstrj --cutoff 3.5
seams cages water.lammpstrj
#+end_src

2.14.0 ships ~libseams~ (~seams.h~) and ~libseams_lang~ in this
tree, with C, C++, Fortran, Rust, Python (~import dseams~), Julia, and
R fronts, plus LAMMPS, GROMACS, OpenMM, PLUMED, and in-situ hooks.
Lua and Fennel ~require("dseams")~ are in this tree as well.
The released Frame package stays separate:

- Python Frame: ~pydseams~ ([[https://d-seams.github.io/PydSEAMSlib/][Python docs]],
  [[https://github.com/d-SEAMS/PydSEAMSlib][PydSEAMSlib]]), compiled
  module ~yoda~
- Lua/Fennel: ~dseams~ ([[https://d-seams.github.io/yodaStruct/][Lua docs]],
  [[https://github.com/d-SEAMS/yodaStruct][yodaStruct]]),
  ~require("dseams")~

The header *Ecosystem* menu on every page jumps between the engine,
the bindings, and linkcell.

Build with a Nix flake (~nix build~, ~nix develop~) or with
~pixi run setup && pixi run build && pixi run test~.
