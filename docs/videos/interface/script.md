# CHILL+ on the paper interface frame

Shot list for a silent picture track. Draft narration is below and in narration.txt. Final wording, edit, and caption timing are recorded later.

Pixi environment: seams-core for the binary, and the dseams-engines manifest (openmm, genice2) for the tutorial driver.

Input data: `generated by docs/tutorials/paper_science.py interface-full`.

Prompt on the terminal shots is `$ `. Commands use the build through `$SEAMS`, `$SEAMS_BUILD`, `$SEAMS_BUILD_SRC`, `$SEAMS_LIBDIR`, `$SEAMS_LANGDIR`, and `$VIDEO_OUT`.

Tests: `docs_paper_interface_full`, `docs_video_tapes`.

Picture: 1920x1080, 30 fps, crf 16, one vhs scene file per shot so the lead-in can be retimed. Each shot starts 0.25 to 0.30 s before the draft line. Captions are a `<track>`, in the empty lower band (`line:95%`), and are not burned in. A later mix uses `-c:a aac -aac_coder fast`.

## Scene 1. Run the tutorial

Lead-in: 0.30 s. Segment length: 12.33 s.

Tests: `docs_video_tapes`, `docs_paper_interface_full`.

Commands:

```bash
python3 docs/tutorials/paper_science.py interface-full "$SEAMS" "$SEAMS_LIBDIR" "$VIDEO_OUT/interface"
```

```text
interface full input molecules 864 frames 1 file-frames 1 file input/traj/interface_f0.lammpstrj
interface full paper molecules 864 frames 1
interface full published hexagonal 352 interfacial 49 water 434 clathrate 3 interClathrate 25

```
