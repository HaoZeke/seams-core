# The brine front

Shot list for a silent picture track. Draft narration is below and in narration.txt. Final wording, edit, and caption timing are recorded later.

Pixi environment: seams-core for the binary, and the dseams-engines manifest (openmm, genice2) for the tutorial driver.

Input data: `generated by docs/tutorials/paper_science.py brine-full`.

Prompt on the terminal shots is `$ `. Commands use the build through `$SEAMS`, `$SEAMS_BUILD`, `$SEAMS_BUILD_SRC`, `$SEAMS_LIBDIR`, `$SEAMS_LANGDIR`, and `$VIDEO_OUT`.

Tests: `docs_paper_brine_full`, `docs_video_tapes`.

Picture: 1920x1080, 30 fps, crf 16, one vhs scene file per shot so the lead-in can be retimed. Each shot starts 0.22 to 0.30 s before the draft line. Captions are a `<track>`, in the empty lower band (`line:95%`), and are not burned in. A later mix uses `-c:a aac -aac_coder fast`.

## Scene 1. Run the tutorial

Lead-in: 0.30 s. Segment length: 12.33 s.

Tests: `docs_video_tapes`, `docs_paper_brine_full`.

Commands:

```bash
python3 docs/tutorials/paper_science.py brine-full "$SEAMS" "$SEAMS_LIBDIR" "$VIDEO_OUT/brine"
```

Expected output (substrings the run must print):

```text
brine full input molecules 873 frames 1 file-frames 1 file input/traj/nacl_front.lammpstrj
brine full paper waters 864 ions 9 frames 1
brine full waters 864 ions 9 hexagonal 352 water 434
```

Draft narration:

The brine frame is input/traj/nacl_front.lammpstrj, 873 atoms in 1 frame: 864 waters and 9 ions. Hexagonal is 352 and water is 434. docs_paper_brine_full asserts those lines.
