Lua
===

LDoc writes ``docs/lang-lua`` from ``bindings/lua/dseams.lua``.
The docs job runs ``ldoc --fatalwarnings``.

The module comment states the Ice Ih census, and
``docs/examples/core_counts.lua`` asserts it: 128 hexagonal waters and
256 six-rings (``by_size[6]``).
